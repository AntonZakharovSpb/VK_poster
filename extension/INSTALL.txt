Три Слога — Chrome extension 0.5.3

INSTALL / UPDATE
Open chrome://extensions in your normal Chrome profile.
Enable Developer mode, then Load unpacked and choose this extension folder.
For an existing installation, click Reload and refresh your VK community tab.

USE
Log into VK. Choose Amount (1–1000 posts) and Interval (1–86400 seconds).
Click «Запланировать партию». Keep Chrome and the VK community tab open.
Progress shows how many posts have been confirmed in «Отложенные».

DATE SEQUENCE
Read https://vk.ru/wall-220995299?postponed=1 in a temporary tab using your
VK login, then close it. Read dates from post headers, loading more
posts where necessary. Schedule the first new post one day later, preserving
the time, then one post per following day. If there are explicitly no queued
posts, start tomorrow at the current Moscow time. Dates use Europe/Moscow.
Interval is the minimum pause between creating posts, not between publication dates.
This version disables the old hourly automatic schedule.

CONTENT
Choose a random song heading and verse from the shared Google document.
Append «Три слога - <song title>». Choose a random native community photo
from the scrolling Фото VK grid. No downloads/uploads or album tabs.
Search music by the text's song title, prefer a similar result credited to
Три слога, including collaborations. If absent, search a random reserve
community song; if it cannot be matched, use the first reserve search result.
Verify attachments and schedule through «Запланировать», not «Опубликовать».
Confirm the post and its date in «Отложенные» before increasing progress.

CAPTCHA
Stop actions whenever a visible CAPTCHA is detected. Solve it yourself in VK,
then click «ОК — продолжить» in the extension. Merely hiding/solving the
challenge does not resume the batch. «Остановить» cancels remaining work.

ERRORS / RESTART
Errors show their reason and enable «Исправлено — повторить».
An uncertain submission requires checking «Отложенные» before retrying.
Closing the browser or VK tab pauses the batch and retains progress.
Resume manually after checking VK. Do not close Chrome during normal work.
Errors automatically download diagnostics/logs as Tri-Sloga-diagnostics-YYYY-MM-DD_HH-MM-SS.json
to your Chrome download folder. No button is needed.
The date picker supports date/time inputs and datetime-local.
The calendar popup is supported, including month/year navigation and time selection.

TESTING
Automated tests use simulated offline VK pages only. They never create real
posts. Actual VK controls can vary; unsupported controls stop safely.
