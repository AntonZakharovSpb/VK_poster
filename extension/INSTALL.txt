AZ_vk_poster — Chrome extension 0.6.0

INSTALL / UPDATE
1. Open chrome://extensions in Chrome and enable Developer mode.
2. Click Load unpacked and select:
   C:\Users\Anton\Documents\VK_poster\extension
   Select the extension folder, not the project root or the old ZIP.
3. If this folder is already installed, click Reload and refresh the VK tab.
   If the old extension uses another folder, disable it before loading this one.
4. Pin AZ_vk_poster in the Chrome extensions menu.

RUN
1. Sign in to VK with permission to create posts in your community.
2. Open AZ_vk_poster and enter the community link, artist, and Google Docs link.
   Community and document fields start empty. Saved settings remain saved.
   Artist defaults to «Три слога». Community links may use vk.ru or vk.com,
   a short name, club<ID>, or public<ID>.
   «Без аудио» disables the artist field and skips music attachment.
   «Без текста» disables the document field and skips text and document fetching.
   Enable both options for a photo-only post.
3. Click «Сохранить настройки». The fields remain saved when the popup closes.
4. Set Amount and Interval (seconds between creating posts).
5. Click «Запланировать партию» and keep Chrome and the VK tab open.
   Starting also saves the fields. Stop the batch before editing its settings.

GOOGLE DOC FORMAT
The document must be readable through its link without signing in.
Use heading styles for song titles and paragraphs for lyrics. Separate verses
with empty paragraphs. The existing logic picks a random song and verse,
then appends «<artist> - <song title>».

POSTS
Scheduling is unchanged: inspect the selected community's postponed queue,
start one day after its latest post, preserve its Moscow time, then use one
consecutive day per new post. An explicitly empty queue starts tomorrow.
Photos remain random native photos of the selected community.
Music search first uses the selected artist and document song title.
If that fails or no title is available, search by artist name only and select
a random matching track, including collaborations. If none match the artist,
take the first available search result. An entirely empty search pauses the batch.
«Не кота бот» by «Три слога» is always excluded from audio selection.
Unconfirmed sends remain in logs and diagnostics; their dates are not listed
in the popup, and the batch continues without repeating the send.

RECOVERY
Solve CAPTCHA in VK and click «Ок — продолжить» in the popup.
For an error, inspect the downloaded diagnostics, fix the problem, and click
«Исправлено — повторить». Check VK before resuming an uncertain submission.
