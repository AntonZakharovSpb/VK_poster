Три Слога — Chrome extension 0.2.0

INSTALL ONCE
1. In your NORMAL Chrome window, open chrome://extensions
2. Enable Developer mode (Режим разработчика).
3. Click Load unpacked (Загрузить распакованное расширение).
4. Choose the extension folder in your downloaded or cloned project.
5. Pin "Три Слога — публикации VK" using Chrome's Extensions menu.

USE
Log into VK in your normal Chrome profile.
Open https://vk.ru/tri_sloga_band and click the extension icon.
Choose the interval in hours (minimum 0.5) and click "Включить".
The first post starts immediately. Later posts are attempted at that interval.
Only the interval is configurable: quotes, photos and songs are selected
automatically, and Publish is clicked after all attachment/author checks pass.
The extension reuses an existing community tab. If there is no community tab,
it opens one in the same Chrome profile; other tabs are preserved.
The job continues in the page when the popup closes. Its log appears in the
bottom-right corner of VK. "Остановить" stops subsequent actions.
If VK ignores the automatic Create action, the scheduled job stops and
notifies you; it does not wait for a manual click.

SCHEDULE AND ALERTS
Chrome must be running and your computer awake. A missed interval after sleep
or a browser restart runs at most once, without publishing a backlog.
The enabled state, interval and next attempt are saved in extension storage.
Reloading the extension resumes that schedule; it does not immediately post
again unless an attempt is due. Changing an active interval schedules the
next attempt from now without an additional immediate publication.
Click "Остановить" to disable the schedule and stop subsequent job actions.
An already submitted post cannot be recalled by Stop.

If VK cannot load within 45 seconds, a Windows notification suggests checking
your VPN and connection. This detects a loading failure, not the VPN itself.
Other publication errors also produce a notification. A red toolbar badge
and the last error in the popup remain available if Windows silences alerts.
Click a notification to open or select the community tab.
The next normal interval is retained after failure; there is no rapid retry.
An interrupted job is reported by a 15-minute watchdog.

UPDATING AN EXISTING INSTALLATION
Click Reload on this extension's card in chrome://extensions, then refresh
the VK community tab. No reinstallation or new VK login is required.

Photo source: https://vk.ru/tri_sloga_band#section=photos
Music source: the community's Music tab. Media IDs are checked against the
community's owner ID -220995299. Selection is random among loaded items.
If Photos shows albums, a random loaded album is opened in a temporary inactive
tab, a photo is chosen from its loaded items, and the temporary tab is closed.
This is not a uniform sample of every photo in all albums.
Photo image: the rendition displayed by VK, downloaded and uploaded into the
new post. It is not guaranteed to be the original full-resolution photo.
Audio: match the community audio ID when VK exposes it. In modern music
pickers without IDs, require a unique matching title, artist and duration.
Quote: fetched from Russian Wikiquote, with source credit, or enter your own
text containing the whole word любовь or счастье.

Each scheduled attempt clicks Publish ONCE after checking photo, audio and
community author. Existing drafts are preserved and cause the attempt to stop.
The modern settings screen uses compact song/photo previews. Song selection
is checked in the picker first, then its final title and artist are checked.
If the modern group editor has no author selector, its destination is checked
from the community admin Create block that opened the dialog. An explicit
author selector takes precedence and must identify the community.
If a publication result is uncertain, sending again is blocked. Check the
wall before using the panel button that permits a new attempt.
Do not use the older Windows publisher at the same time.

STATUS
The package and browser fixture tests have been checked. End-to-end posting
has NOT been confirmed in your normal Chrome session. VK's live editor,
upload preview, author selector and music picker may require calibration.
On an error the extension leaves VK open and records the failing stage.
Click "Диагностика" in the extension popup to save tri-sloga-diagnostic.json.
The report contains UI labels, media IDs and logs, not browser cookies or
access tokens. Keep it private if it contains personal UI labels.

CUSTOMIZE
All source is in this folder. Edit popup.html/popup.css for the controls,
content.js for media/editor behavior, background.js for quote/image fetching,
and scheduler.js for the interval, tab loading, and notification behavior.
After an edit, click Reload on the extension's card in chrome://extensions
and refresh the VK tab so it uses the new content script.
No Python, VPN, paid API or cloud AI is needed by the extension.
Chrome does not allow ordinary unsigned extensions to be installed simply
by double-clicking a file; the Load unpacked step is required.

PERMISSIONS
VK: operate in your community tab with your existing login.
Wikiquote: fetch Russian quotes.
VK image hosts: fetch the selected community photo.
Local extension storage: schedule, status, operation lock and diagnostics.
Alarms: wake the extension worker for scheduled attempts and the watchdog.
Notifications: report failed or interrupted attempts to Windows.
The extension does not read browser cookie APIs or store your password.
