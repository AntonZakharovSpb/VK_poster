AZ_vk_poster — инструкция для нового пользователя
Версия 0.9.0

1. Что понадобится
Компьютер с Google Chrome, интернет, аккаунт VK и права создавать записи
от имени нужного сообщества. Python, Node и Git для использования не нужны.
Расширение работает через открытый интерфейс VK. Оставьте Chrome и вкладку
сообщества открытыми, пока создаётся партия; не редактируйте её посты вручную
параллельно и не переводите компьютер в сон.

2. Скачать проект с GitHub
Откройте https://github.com/AntonZakharovSpb/VK_poster и войдите в GitHub.
Репозиторий закрытый: нужен доступ, предоставленный владельцем. Если видите
404, проверьте аккаунт и попросите владельца предоставить доступ.
Выберите ветку main, затем зелёную кнопку Code -> Download ZIP.
Распакуйте ZIP полностью в постоянную папку, например Documents\VK_poster.
Не удаляйте и не перемещайте эту папку после установки.
Внутри проекта должна быть папка extension с файлом manifest.json.

3. Установить расширение
В адресной строке Chrome откройте chrome://extensions/.
Включите «Режим разработчика», нажмите «Загрузить распакованное расширение».
Выберите именно папку extension, а не ZIP и не корневую папку проекта.
В списке появится AZ_vk_poster. Нажмите значок пазла в Chrome и закрепите его.
Разрешён доступ к VK, Google Документам и русскому Викицитатнику для загрузки
текста. Проверьте номер версии в окне расширения.

4. Подготовить сообщество
Войдите в VK в этом же Chrome и откройте нужное сообщество.
Проверьте, что можете создать отложенную запись от имени сообщества.
В сообществе должны быть фотографии: расширение выбирает случайную из них.
Закройте незавершённые редакторы записей перед запуском.

5. Заполнить настройки
Нажмите значок AZ_vk_poster.
«Ссылка на сообщество VK»: вставьте https://vk.ru/имя или https://vk.com/club123.
По умолчанию ссылка пустая. Это должна быть страница сообщества, не профиль,
отдельная запись, альбом или страница списка новостей.
«Исполнитель для прикрепленных треков»: имя артиста; по умолчанию Три слога.
«Без аудио»: выключает поле и полностью пропускает поиск/прикрепление трека.
«Без текста»: выключает поля текста и полностью пропускает его добавление.
Настройки сохраняются кнопкой «Сохранить настройки»; запуск тоже сохраняет их.
Во время партии настройки заблокированы. Для изменения сначала остановите её.

6. Выбрать текст
А. «Документ по ссылке».
Создайте Google Документ, откройте доступ «Все, у кого есть ссылка» для чтения
и вставьте ссылку https://docs.google.com/document/d/ID/edit.
Оформите название каждого текста стилем «Заголовок», не просто жирным шрифтом.
Под заголовком разместите текст; пустыми абзацами разделите его на куплеты.
На каждый пост выбираются случайный текст и случайный куплет.
Флаг «по-порядку» под ссылкой выключает случайный выбор: куплеты/пункты идут
в порядке документа. Новая партия начинает с первого; после последнего идёт
снова первый. При продолжении партии сохраняется место, при повторной попытке
используется тот же пункт. Без флага выбор остаётся случайным.
Документ без заголовков: сначала выбирается случайный пункт нумерованного
списка или списка с «-». Пункты могут содержать несколько строк/абзацев.
Если списка нет, выбирается случайная часть между пустыми строками.
Если таких частей нет, выбирается случайный абзац. Подпись без названия текста.
Последняя строка: Название сообщества - Название текста.
Если заголовка нет: только название сообщества.

Б. «Случайная цитата из интернета».
Введите слово или фразу по теме, например «любовь» или «дружба».
Расширение ищет в русском Викицитатнике и случайно выбирает цитату по теме
без требования указанного автора. Автор добавляется, если его удалось определить;
если автора нет, дополнительный поиск не выполняется. Последняя строка
«Источник:» содержит ссылку на страницу, где цитата найдена.
Цитаты не генерируются. Если подходящей цитаты нет, партия остановится:
попробуйте более простое слово или другой источник текста.
Для этого режима нужен доступ к ru.wikiquote.org.

В. «Один текст для всех постов».
Введите свой текст в поле. Во всех постах партии будет один и тот же текст,
с сохранением переносов строк. Последняя строка — название сообщества.
В режимах Б и В название песни не задаётся: музыка ищется по исполнителю.

7. Музыка
В режиме документа сначала ищется исполнитель + название текста.
Если песня не найдена или названия нет, выбирается случайный трек артиста.
Если трека с ТОЧНО таким именем исполнителя нет, выбирается случайный трек
группы «Три слога». Chrome покажет уведомление проверить точное имя артиста;
предупреждение также видно в окне расширения, партия продолжается.
Уведомление появляется один раз за партию. Если нет и допустимых треков
«Три слога», партия остановится. Трек «Не кота бот»
исполнителя «Три слога» (также версии и совместные треки) всегда исключается.

8. Запланировать партию
«Всего постов (Amount)»: общее количество записей, от 1 до 1000, на все дни.
«Пауза, сек. (Interval)»: задержка между созданием записей, от 1 до 86400.
«Постов в день»: от 1 до 12. «Время начала (Москва)»: время первого поста дня.
«Интервал2 внутри дня, часы»: расстояние между публикациями в течение дня.
Можно задавать дробные часы, например 1.5 = полтора часа, с точностью до минуты.
Начало + Постов в день × Интервал2 должно быть строго меньше 24:00.
Например, 3 поста, начало 09:00 и Интервал2 = 2: времена 09:00, 11:00, 13:00.
Для пяти постов всего это три в первый день и два во второй.
Время повторяется каждый день, последние посты не переходят через полночь.
Нажмите «Запланировать партию». Расширение проверит список «Отложенные».
Оно прокручивает список до самого конца, загружает дальнейшие записи и ждёт
завершения загрузки, чтобы найти последнюю дату во всей очереди.
Первый день — день после последнего отложенного поста, или завтра при пустой
очереди. Первый пост ставится в выбранное время начала, все времена по Москве.
При продолжении партии оставшиеся слоты того же дня сохраняются. Если за время
паузы добавили более поздние посты извне, оставшиеся начнутся на день после них.
Проверка очереди выполняется при старте/продолжении, а не после каждого поста.
После отправки закрытие редактора без новой ошибки VK считается успехом.
Дождитесь сообщения «Партия завершена» и проверьте записи в VK -> «Отложенные».
«Остановить» отменяет оставшуюся работу, уже созданные записи сохраняются.

9. CAPTCHA и ошибки
Если появилась CAPTCHA, решите её во вкладке VK и нажмите в расширении
«ОК — продолжить». Если ошибка остановила партию, исправьте указанную причину,
проверьте «Отложенные» и нажмите «Исправлено — повторить».
При ошибках диагностика автоматически сохраняется в папку загрузок Chrome:
Tri-Sloga-diagnostics-ДАТА_ВРЕМЯ.json. Передайте файл разработчику при необходимости.
После каждого поста вкладка очереди не открывается; расширение продолжает
после закрытия редактора без ошибки. Итоговую очередь можно проверить вручную.
При закрытии Chrome или вкладки VK незавершённая партия приостанавливается.

10. Обновить расширение
Когда владелец опубликует новую версию в main, скачайте новый ZIP и распакуйте
его в ту же постоянную папку, заменив старые файлы. Сначала остановите партию.
Откройте chrome://extensions/ и нажмите значок обновления на AZ_vk_poster.
Обновите вкладку VK, откройте расширение и проверьте новый номер версии.
При новой запрошенной доработке номер версии увеличивается.
Для тестовой версии используйте ветку, указанную разработчиком, вместо main.
Если Chrome просит разрешить доступ к новому источнику, разрешите его.
